# Time Trek: Prehistoric World

Time Trek is an interactive educational application that allows users to explore prehistoric life across geological eras using AI-generated reconstructions and guided storytelling. The project aims to move beyond static textbooks and transform learning into an exploratory, visual experience driven by curiosity.

Instead of reading isolated facts, users travel through time from the Precambrian oceans to Jurassic forests and Ice Age tundras, interacting with extinct species through immersive descriptions, visual environments, and fossil-grounded explanations.

The application is built using **Gemini 3 Pro** in **Google AI Studio** and leverages multimodal AI to generate adaptive educational content for different age groups while maintaining scientific accuracy.

## Key Features

- Era-based exploration of prehistoric life
- AI-generated species descriptions and visual reconstructions
- Fossil references, habitat context, and dietary information
- Age-adaptive explanations suitable for kids and adults
- Storytelling and fun-facts modes for engagement
- Visual simulation of environments across geological timelines
- Educational comparisons such as size vs human and diet types

## How It Works

The system uses structured prompts and fossil-based grounding to guide Gemini’s content generation. Multimodal reasoning is used to produce coherent explanations, visual reconstructions, and narrative descriptions while avoiding factual drift.

Content is dynamically adapted based on the selected era and learner level, allowing the same system to support both introductory learning and deeper exploration.

## Run and Deploy Locally

This repository contains everything needed to run the app locally.

### Prerequisites
- Node.js

### Setup Instructions

1. Install dependencies  

`npm install`

2. Set your Gemini API key  
Create a `.env.local` file and add:
`GEMINI_API_KEY=your_api_key_here`

3. Run the development server
`npm run dev`

## Purpose

Time Trek demonstrates how multimodal AI can turn education into an experience rather than information delivery. By combining reasoning, visual generation, and narrative explanation, the project shows how AI can make science feel like exploration instead of memorization.
